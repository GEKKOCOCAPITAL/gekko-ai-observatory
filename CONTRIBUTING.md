# Contributing

Issues and pull requests are welcome, in English, French or German.

* Run `pytest -q` and `luxfin run` before opening a pull request; no validation check may return FAIL.
* Data changes: keep the `status` / `source` columns up to date and add the source to `data/sources.csv`.
* Risk-weight changes (`data/risk_taxonomy.yaml`): explain the reasoning and the regulatory reference in the pull request.
* Do not commit personal data, confidential institution data or credentials.
